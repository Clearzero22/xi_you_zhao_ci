     Plan: Concurrent Multi-ASIN Scraper

     Context

     Current index.ts only handles a single ASIN (B0DZFGTCLR). The user wants to
      query multiple ASINs concurrently by opening 3 browser tabs and running
     the same workflow (search → select all → batch copy → read clipboard) in
     parallel.

     Approach

     1. Extract single-ASIN logic into a reusable function

     - Move the core workflow (L18-97 in index.ts) into scrapeAsin(page: Page, 
     asin: string): Promise<string | null>
     - Each tab gets its own page, runs independently
     - Returns the clipboard content (keyword data) or null on failure

     2. Concurrent orchestration

     - Define TARGET_ASINS: string[] with multiple ASIN values
     - Use Promise.allSettled() with a concurrency limit of 3 (semaphore pattern
      using a simple queue or p-limit-like approach)
     - Each concurrent task: opens a new tab → runs scrapeAsin → closes tab →
     writes result to separate file

     3. Output

     - Save each ASIN's results to ./keywords-{ASIN}.txt instead of a single
     keywords-copied.txt
     - Print summary at the end: which ASINs succeeded/failed

     4. Clipboard concern

     - Critical: clipboard is shared OS state. Multiple tabs writing to
     clipboard simultaneously will cause data races.
     - Solution: After each tab clicks "批量复制", immediately read clipboard
     within that tab before other tabs can overwrite it. Sequence within each
     tab is: click copy → read clipboard → save → next step. Since JS is
     single-threaded per page, this is safe as long as tabs don't interleave the
      copy-read cycle.
     - Add a small random delay (500-1500ms) between tab launches to stagger the
      operations.

     Files to modify

     - index.ts — refactor into concurrent version

     Verification

     - Run bun run index.ts and verify 3 tabs open simultaneously
     - Each tab queries a different ASIN and saves its own output file
     - No clipboard conflicts (each tab reads immediately after its own copy)
